# B-013: Shown Encounter Button Height Mismatch

## Summary

The green Encounter card `Shown to Players` button from F-010G visually appears
taller than the normal `Show to Players` button, shifting card controls.

## Status

Resolved.

## Observed Behavior

On the Encounter gallery, the currently shown encounter's green
`Shown to Players` button appears taller than neighboring `Show to Players`
buttons.

## Expected Behavior

The `Shown to Players` and `Show to Players` Encounter card buttons should keep
the same compact rendered height as the other Encounter card buttons while
using different colors to communicate state.

## Reproduction

1. Open a campaign with at least two encounters.
2. Show one encounter to players.
3. Compare the shown encounter's green `Shown to Players` button with another
   encounter's `Show to Players` button.
4. Confirm the shown-state button appears taller.

## Affected Systems

- GM view: Encounter card shown-state button styling.
- Player view: unchanged.
- Local server: unchanged.
- Map/fog rendering: unchanged.
- Storage: unchanged.
- Network/device setup: unchanged.
- Documentation: bug tracker and F-010G evidence.

## Investigation Notes

- The issue was reported by the user with a screenshot on 2026-07-31 during
  F-010G validation.
- The shown-state CSS added an inset box shadow to the green button.
- The card layout can also produce different button heights when action text or
  card width changes.
- The fix removes the extra inset treatment and gives Encounter card running
  buttons the same compact minimum height and padding as the other Encounter
  card controls.

## Validation Plan

Browser regression coverage compares the actual rendered height of a green
`Shown to Players` Encounter button with both a normal `Show to Players`
Encounter button and an Encounter management button. Run focused Chromium
coverage and full `npm run quality`.
