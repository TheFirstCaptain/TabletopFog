# F-010E: Handout Rename and Delete

## Objective

Allow the GM to rename and delete campaign handouts after the basic handout
library exists.

## User Value

The GM can keep campaign handouts tidy as prep changes without manually editing
campaign files.

## Non-Goals

- Do not change handout show-to-players behavior.
- Do not change handout rotation behavior.
- Do not add PDFs, text handouts, notes, folders, tags, search, or slideshow
  mode.
- Do not add encounter-specific handouts.

## Acceptance Notes

- The GM can rename a handout without changing its stored asset path.
- The GM can rename only handouts that are not currently shown to players.
- The GM can delete an unshown handout with confirmation.
- Rename and delete controls are blocked for a handout currently shown to
  players.
- Deleting handouts removes the copied asset and metadata together.
- Failed rename or delete operations leave handout files and metadata
  unchanged.
- Browsing, renaming, or deleting handouts does not change the Player Display.
- Deleting an unshown handout does not change a different encounter or handout
  currently shown to players.
