# F-010F: Encounter Selected Prep Card Polish

## Objective

Remove the redundant card-level `Selected for Prep` status pill from Encounter
cards while keeping the selected-prep highlight.

## User Value

The GM can scan the Encounter gallery without selected cards shifting content
or repeating the same state through both a highlight and a text pill.

## Non-Goals

- Do not change which encounter is selected for prep.
- Do not change Encounter Workspace status copy.
- Do not change `Shown to Players` status, clear behavior, or Player Display
  state.
- Do not change storage, server routes, Socket.IO synchronization, map/fog
  rendering, handouts, upload, rename, reorder, or delete behavior.

## Acceptance Notes

- A selected-prep Encounter card keeps its visual highlight.
- A selected-prep Encounter card no longer shows a `Selected for Prep` text
  pill.
- The selected card exposes the selected state with `aria-current`.
- `Shown to Players` remains a visible card status and clear action.
- Opening an encounter for prep still does not change the Player Display.
- The Encounter Workspace status can still identify the selected-prep
  encounter.
