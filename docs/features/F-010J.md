# F-010J: Player-Local Handout Rotation Controls

## Objective

Add Player Display toolbar buttons that let players rotate a shown handout in
90-degree increments.

## User Value

Players can correct the viewing orientation of a handout on the table display
without asking the GM to adjust it, while the GM remains in control of what
content is shown.

## Non-Goals

- Do not let players choose, show, clear, upload, rename, delete, or reorder
  handouts.
- Do not let players change shared campaign state or persisted shown-target
  rotation.
- Do not add arbitrary-angle rotation.
- Do not rotate encounter maps or fog.
- Do not add crop, flip, brightness, annotation, image editing, slideshow
  behavior, folders, tags, or search.
- Do not change GM-controlled rotation behavior, GM preview rotation, handout
  storage, server routes, Socket.IO synchronization, or current-target asset
  access unless implementation review determines a reclassification is needed.
- Do not add tokens, initiative, dice, notes, character sheets, rules
  automation, dynamic lighting, cloud hosting, login, or authentication.

## Acceptance Notes

- When the Player Display is showing a handout, the existing image toolbar
  includes rotate-left and rotate-right controls alongside zoom, reset, and
  fullscreen controls.
- Player rotation controls rotate only the local Player Display handout view in
  90-degree increments.
- Player rotation supports only `0`, `90`, `180`, and `270` degree orientations.
- Player rotation does not change the GM View, campaign storage, shown-target
  state, or any other connected Player Display.
- Player rotation controls are hidden or disabled when the Player Display is
  showing an encounter map, waiting state, or error state.
- GM-controlled handout rotation remains shared display state and still updates
  the Player Display baseline orientation.
- If the GM rotates the shown handout after a player-local rotation, the Player
  Display applies the player's local quarter-turn offset on top of the updated
  GM-controlled baseline.
- Changing the shown target resets player-local handout rotation to `0`.
- Player-local rotation works with zoom, reset, pan, and fullscreen without
  layout overlap or toolbar crowding.
- The Player Display remains read-only: player controls affect only local
  presentation, not campaign state.
