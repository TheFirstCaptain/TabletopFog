# F-010C: GM-Controlled Handout Rotation

## Objective

Let the GM rotate a shown handout in 90-degree increments.

## User Value

The GM can quickly correct image orientation for the player-facing TV or iPad
without editing the source image outside TabletopFog.

## Non-Goals

- Do not add arbitrary-angle rotation.
- Do not add player-side rotation.
- Do not rotate encounter maps.
- Do not add crop, flip, brightness, annotation, or image-editing tools.
- Do not add slideshow behavior.

## Acceptance Notes

- Rotation supports only `0`, `90`, `180`, and `270` degrees.
- Rotation is controlled by the GM.
- Rotation updates the Player Display only for the handout currently shown to
  players.
- Rotation controls appear only for the handout currently shown to players.
- Browsing or selecting an unshown handout in the GM View does not change or
  rotate the Player Display.
- Rotation state is part of the shown handout display state.
- Showing a handout starts at `0` degrees; re-showing a handout does not
  inherit a previous shown-display rotation.
- Rotation preserves fullscreen handout display behavior.
- Rotation does not affect encounter maps or fog.
