# F-010H: Handout Gallery Card Polish

## Objective

Make campaign Handout cards visually align with the polished Encounter card
gallery by removing redundant status/count UI and using the same
`Show to Players` / `Shown to Players` button treatment.

## User Value

The GM can switch between `Encounters` and `Handouts` without the page changing
visual language, card rhythm, or control behavior. The shown handout remains
obvious through the action button itself, without extra status pills shifting
card content.

## Non-Goals

- Do not change handout upload, rename, delete, rotation, storage, or recovery
  behavior.
- Do not change Player Display projection, read-only guarantees,
  synchronization, or shown-target persistence.
- Do not change Encounter card behavior.
- Do not add new handout formats, folders, tags, search, slideshow controls, or
  overlay behavior.
- Do not add tokens, initiative, dice, notes, character sheets, rules
  automation, dynamic lighting, cloud hosting, login, or authentication.

## Acceptance Notes

- The Campaign `Handouts` tab no longer shows the horizontal divider directly
  below the `Encounters` / `Handouts` tab controls.
- The Campaign `Handouts` tab no longer shows the handout count text.
- Handout cards no longer show a separate card-level `Shown to Players` status
  pill.
- The existing Handout card action still changes from `Show to Players` to
  `Shown to Players` when that handout is shown.
- The `Shown to Players` Handout card action is green and remains an enabled
  clear action.
- The Handout card `Show to Players` and `Shown to Players` actions use the
  same compact rendered size and visual behavior as Encounter card actions.
- Clearing a shown handout returns the action to `Show to Players`.
- Switching between `Encounters` and `Handouts` keeps the gallery presentation
  consistent and does not change the Player Display.
- Handout rename/delete guards and rotation controls keep their existing
  behavior.
