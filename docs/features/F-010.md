# F-010: Campaign Image Handouts

## Objective

Allow the GM to add campaign-wide image handouts and explicitly show one
handout on the Player Display.

## User Value

The GM can show portraits, clues, scenery, item art, and other non-map images
to players during an in-person session without creating a map-backed encounter
or adding VTT-style notes.

## Non-Goals

- Do not add PDFs.
- Do not add text handouts or notes.
- Do not add encounter-specific handouts.
- Do not add folders, tags, search, or slideshow mode.
- Do not overlay handouts on top of maps.
- Do not add player-side rotation.
- Do not add arbitrary-angle rotation.
- Do not add tokens, initiative, dice, character sheets, rules automation,
  dynamic lighting, cloud hosting, login, or authentication.

## Acceptance Notes

- Campaigns can contain image handouts separate from encounters and maps.
- Handouts are campaign-wide, not encounter-specific.
- The first supported handout inputs are image files only.
- The GM can explicitly show one handout to players.
- Showing a handout replaces the currently shown encounter or map on the Player
  Display.
- Showing an encounter again replaces the shown handout.
- Browsing, adding, renaming, selecting, or rotating a handout in the GM View
  must not change the Player Display unless the GM explicitly shows the
  handout.
- The Player Display remains read-only.
- Existing Player Display fullscreen behavior applies to handouts.
- The GM can rotate the shown handout in 90-degree increments.
- Rotation is GM-controlled shared display state for the shown handout.
- Rotation supports only `0`, `90`, `180`, and `270` degrees in the first
  version.
