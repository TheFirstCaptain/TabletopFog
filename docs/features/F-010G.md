# F-010G: Encounter Shown Button Polish

## Objective

Remove the separate card-level `Shown to Players` pill from Encounter cards and
make the existing shown-state Encounter action button green.

## User Value

The GM can scan Encounter cards without status pills shifting the vertical
position of running and management controls, while the currently shown
encounter remains obvious through the action button itself.

## Non-Goals

- Do not change `Show to Players` or clear behavior.
- Do not change Player Display state, projection, read-only guarantees, or
  synchronization.
- Do not change Encounter Workspace status copy.
- Do not change handout card status pills.
- Do not change storage, server routes, map/fog rendering, upload, rename,
  reorder, delete, or handout behavior.

## Acceptance Notes

- Encounter cards no longer show a separate `Shown to Players` status pill.
- The existing Encounter card action still changes from `Show to Players` to
  `Shown to Players` when that encounter is shown.
- The `Shown to Players` Encounter card action is green and remains an enabled
  clear action.
- The green `Shown to Players` action keeps the same compact rendered height as
  normal `Show to Players` and management actions.
- Clearing a shown encounter returns the action to `Show to Players`.
- Opening an encounter for prep still does not change the Player Display.
- Handout card status pills are unchanged.
