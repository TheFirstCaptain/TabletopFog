# F-010B: Show Handout to Players

## Objective

Allow the GM to explicitly show one campaign handout on the Player Display.

## User Value

The GM can reveal a portrait, clue, location image, or other prepared visual at
the table without creating an encounter or map.

## Non-Goals

- Do not add handout storage; build on F-010A.
- Do not add rotation; track that in F-010C.
- Do not overlay handouts on top of encounter maps.
- Do not add player-side controls that mutate shared state.
- Do not add slideshow behavior.

## Acceptance Notes

- Each handout has an explicit `Show to Players` action.
- Showing a handout replaces the currently shown encounter on the Player
  Display.
- Showing an encounter again replaces the shown handout.
- Clearing the Player Display is part of this slice and works for both shown
  encounters and shown handouts.
- Opening, browsing, or selecting a handout in the GM View does not change the
  Player Display.
- The Player Display renders only the currently shown target: empty, encounter,
  or handout.
- The Player Display remains read-only.
- Existing Player Display fullscreen support works while a handout is shown.
- Missing or invalid shown handout assets fail to a safe Player Display state
  and report useful GM-only diagnostics.
