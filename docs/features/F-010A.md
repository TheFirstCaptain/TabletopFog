# F-010A: Campaign Handout Library

## Objective

Add campaign-wide image handout storage and GM browsing controls separate from
encounter maps.

## User Value

The GM can prepare non-map images for a campaign without forcing each image
into the encounter workflow.

## Non-Goals

- Do not show handouts to players in this slice.
- Do not add rotation.
- Do not add PDFs, text handouts, notes, folders, tags, search, or slideshow
  mode.
- Do not add encounter-specific handouts.

## Acceptance Notes

- A campaign can store handout metadata separately from encounter map metadata.
- Handout image assets are copied into a campaign-local handout asset folder.
- Original filenames are preserved as default display names.
- Supported image types should align with map image support unless a planning
  review identifies a reason to narrow them.
- Invalid, mismatched, oversized, partial-failure, and missing-asset cases must
  leave existing campaign data and assets unchanged where practical.
- Browsing, adding, renaming, or deleting handouts does not change the Player
  Display.
